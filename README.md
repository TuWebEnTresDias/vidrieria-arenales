# Vidriería Arenales

Borrador estático personalizado, preparado para revisión en la URL prevista de GitHub Pages. No requiere compilación ni dependencias.

## Datos incorporados

- El chat confirma que el negocio ofrece vidriería y aberturas.
- La ficha del lead aporta dirección y horarios de atención.
- El teléfono de contacto es el número de WhatsApp provisto para el negocio.

No se incluyeron calificaciones, reseñas, promesas comerciales ni servicios adicionales que no estuvieran confirmados. La vista previa conserva `noindex,follow` hasta que se apruebe el sitio final.

## Contacto y medición

El formulario no envía ni almacena datos: solo prepara un mensaje para WhatsApp después de que la persona lo completa. PostHog registra visitas a la página; no se habilitaron autocaptura, grabación de sesión ni identificación de usuarios.

Antes de indexar o presentar la página como final, confirmar el contenido con el negocio y reemplazar las imágenes ilustrativas si envía fotos propias.
