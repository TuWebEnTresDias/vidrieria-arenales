# Instrucciones del repositorio

## Estado y arquitectura

- Sitio estático en HTML, CSS y JavaScript, alojado en la raíz del repositorio para GitHub Pages.
- Esta versión es una vista previa comercial, no un lanzamiento final. Mantener `noindex,follow` hasta que Nacho apruebe publicar la versión final.
- No agregar CNAME, cambiar el dominio ni habilitar indexación sin autorización explícita.

## Contenido y fuentes

- El chat confirma vidriería y aberturas. La ficha del lead aporta dirección, horarios y teléfono.
- No inventar servicios, cobertura, reseñas, calificaciones, años de experiencia, garantías ni resultados.
- Las fotos de `assets/` vienen de la demo `TuWebEnTresDias/demo-vidriero`; mantener sus créditos y presentarlas como ilustrativas, nunca como trabajos del negocio.
- No guardar conversaciones, datos de visitantes, credenciales ni secretos en el repositorio.

## Privacidad y cambios

- El formulario no tiene backend; solo puede abrir WhatsApp después del envío explícito y no debe mostrar una confirmación de entrega.
- PostHog registra pageviews únicamente. Mantener desactivados autocapture, session replay e identificación de usuarios salvo instrucción aprobada.
- Seguir las guías de creación web, seguridad web y SEO de TuWebEn3Dias antes de ampliar el sitio.
